# Pixel Math Paint

Jogo de pintura com matemática feito em Python com a biblioteca Pyxel,
para a disciplina de Algoritmos e Estruturas de Dados I (FURG).

Autora: Amanda Ferreira Duarte | Matícula: 182556

## Ideia do jogo

Uma imagem em pixel art está escondida em uma matriz. Para revelar cada cor,
o jogador resolve um problema de matemática. Ao acertar, aparecem pontos na
tela para clicar e pintar. São 5 níveis, do básico ao Cálculo I.
